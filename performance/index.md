# 绩效规则制定实践

本文件记录量潮在绩效规则制定上的习惯做法，不是一般原则。

## 从记录到章程

绩效建设分三步，先记录，后标准，再章程。

1. 绩效记录只呈现客观事实：产出内容、阶段状态、证据，不做归因。归因与改进属于复盘报告，混进记录会损害记录的公信力。
2. 岗位标准从记录中提炼，一个岗位一份。判定逻辑要能被任职者复述，即任职者能说清自己的工作怎样才算数。
3. 章程在标准经过若干周期检验、不再频繁修订后，提炼共性生成，有案例支撑。

岗位标准至少写明四项：有效性判定条件、判定阶梯、不同类别工作的分项要求、期初约定。

规则制定遵循四步：从真实问题出发提出猜想，回到原始记录溯源验证，反思判定依据，最后写成规则。

## 与职级制度的关系

岗位标准围绕职级设定：越初级的岗位，分工越明确细致，验证落在具体行动上；越高级的岗位，授权范围越大、目标越抽象，验证落在最终结果上。不同职级序列的侧重点不同，由各自的岗位标准规定。

数字资产贡献（协作平台的统计与看板）可以作为初级岗位的参考指标，但不能作为唯一或主要指标——不是所有人的主要贡献都体现为数字资产；生成成本大幅下降后，产出的数量最先失去衡量意义。
